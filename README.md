## 👨‍💻 About Me

Systems Analyst with a strong background in Information Technology, holding a degree in Information Systems and a postgraduate degree in Full Stack Development from PUC Minas. Experience in web development using HTML, CSS, and JavaScript, including integration with REST APIs and file management via FTP. Additional knowledge in React, Python, Java, and C#.

Currently working as a Digital Analyst in a large-scale corporate environment, focusing on frontend development, process automation using Microsoft Power Platform, SQL data queries, and working in Linux environments via SSH (MobaXterm).

Analytical, collaborative, and solution-oriented professional, focused on quality, efficiency, and best development practices.
